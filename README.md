# API Project

This project follows the **MVC (Model-View-Controller)** architecture using Node.js.

## Project Structure

- **controllers/** — Handles the logic of the application (e.g. `user.js`).
- **models/** — Manages data and database schema (e.g. `user.js`).
- **routes/** — Defines API endpoints and connects them to controllers (e.g. `user.js`).
- **middlewares/** — Contains middleware functions (e.g. `index.js`).
- **views/** — Can be used for rendering views or storing templates.
- **connection.js** — Database connection setup.
- **index.js** — Entry point of the application.
